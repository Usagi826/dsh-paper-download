# 发布到 GitHub（双击即可）

右键本文件 → **使用 PowerShell 运行**。脚本只做三件事：初始化仓库、提交、推送。
第一次推送会弹出浏览器，登录 GitHub 并点 **Authorize** 即可（之后不用再登录）。

出错时窗口不会自动关闭，照着屏幕上最后一行红字把内容发给我。
- 若提示 `Permission denied`：本机还没授权，重新双击运行一次，把浏览器弹窗点完。
- 若提示 `Repository not found`：GitHub 上还没建同名仓库，见下面第 0 步。
- 若长时间卡住不动：可能是网络问题，按 `Ctrl+C` 结束后再试。

---

## 第 0 步（只做一次）：在网页上建仓库

打开 <https://github.com/new>：

1. Repository name 填 `dsh-paper-download`
2. 选 **Public**
3. 下面的 “Add a README / .gitignore / license” **都不要勾**
4. 点 **Create repository**

做完后，回来双击本文件。

---

## 之后修改代码再发布

双击 `更新到GitHub.ps1`，它会把新的改动提交并推上去。
